## Decisions taken under PLAN §1.17's rule (safe default, flag, note)

- `native=None` and `native='auto'` never restart a running unit (a plain `lgs on` by any agent must not end another agent's `native-session`); `auto` is resolved only when a new unit starts, in the order flags.json, defaults.json, built-in CSS only.
- The source check for actions uses two things: the binding call's execution context must be SharedJSContext's default context (learned with a nonce probe, so Runtime.enable is not needed on Steam's busiest context), and the claimed `src` must be in the action's `sources`.
- `nav` / `launch` actions are logged and not run while `actionsDryRun` is on **or** P1's runtime action logger (`rt.test.actions.enabled()`) is on; they are recorded there as `daemon.<type>`. If the logger state cannot be read, the action is not run.
- Built-in `sgwindow` action (window dim / recede with a TTL ≤ 60 s, default 10 s) is the CSS-only path for P7's `window` state; it expires by itself so a forgotten request cannot leave the window dimmed.
- `lgs_shell.py start --assume-caps …` (lab only, a CLI option rather than a flag so no shared file is touched) makes the writer act as if glassd announced those caps, so the glassd.json side of DM-2 can be checked before P9's v3 binary is installed.

## Decisions taken under PLAN §1.17's rule (safe default, flag, note)

- **R1: glassd is stopped as soon as the daemon goes dormant** (no warm window). The safe default for "nothing reads the camera with nothing to draw"; the cost is about 2 s more to native after a lab `--stock` step (glassd restarts; 08:53:40 → 08:53:42).
- **R1: `--stay` is bounded by 2400 s** (`STAY_MAX_S`, the PC side of `native-session` gives up after 2400 s), as dormancy grace and as native lifetime; after it the unit is an ordinary CSS-only unit. A constant, not a flag: it guards against an agent that died, which cannot be relied on to set a flag.
- **R1: RAM test plugins** (`/tmp/lgs/shell-ext-test/`) are always scanned, but may only declare kinds `echo` / `read`, so a file in `/tmp` can never navigate, launch or change the UI.
- **R1: `start()` lock** `/tmp/lgs/shell-start.lock` (RAM, 60 s); on a timeout it goes on and treats "already loaded" as running.

- `native=None` and `native='auto'` never restart a running unit (a plain `lgs on` by any agent must not end another agent's `native-session`); `auto` is resolved only when a new unit starts, in the order flags.json, defaults.json, built-in CSS only.
- The source check for actions uses two things: the binding call's execution context must be SharedJSContext's default context (learned with a nonce probe, so Runtime.enable is not needed on Steam's busiest context), and the claimed `src` must be in the action's `sources`.
- `nav` / `launch` actions are logged and not run while `actionsDryRun` is on **or** P1's runtime action logger (`rt.test.actions.enabled()`) is on; they are recorded there as `daemon.<type>`. If the logger state cannot be read, the action is not run.
- Built-in `sgwindow` action (window dim / recede with a TTL ≤ 60 s, default 10 s) is the CSS-only path for P7's `window` state; it expires by itself so a forgotten request cannot leave the window dimmed.
- **Theme off without `lgs off`**: dormant (native layer, reporter, scene graph off; SteamVR page theming and the action binding kept) for `shellThemeGraceS` (default 600 s, flag, `0` = Phase 1's exit after 3 s), then exit; exit at once when the theme is off on a new SharedJSContext target (Steam restarted) and after 120 s without Steam. A bounded wait keeps the transient rule (nothing autostarts: the theme only comes back through someone's `lgs on` / `lgs.op('on')`), and lab `--stock` steps no longer kill the daemon for everyone.
- **A Steam evaluation that times out** is tolerated twice in a row (connection kept, logged once); the third drops the socket as before. Steam's JS thread is often busy for seconds with other agents' audits, and dropping the socket took the native layer down for 2-4 s.
- **`dim` slabs** (glassd G7 room-dim cells) are passed to glassd with their `fill` only when glassd lists `dimSlab`, and go to the scene-graph spec as surface `dimSlabs` (never popped: there is no element to crop). P7 places them when room dim is built (C7's `roomDim` flag is off). `dim` plates need the `dim` cap; `roomDim` (report top level) the `roomDim` cap.
- `lgs_shell.py start --assume-caps …` (lab only, a CLI option rather than a flag so no shared file is touched) makes the writer act as if glassd announced those caps, so the glassd.json side of DM-2 can be checked before P9's v3 binary is installed.
